两首歌各三段，沿用早已锁定的18秒原唱窗口。每段自由选择实际首尾，再记录边缘；五种未解决符号集中在页面末尾。只保存原话，不自动补音素或挑选模型。

1. 六段逐项填写（切换自动保留）

没有机器给定的唯一对应；可搜索并试听全曲参考。找不到时选待定并说明听到的内容，不必强行对齐。

2. 在整首参考里点首字和末字

搜索你听到的几个字（按原参考字形），或直接浏览。每一行都可试听合成参考；同样歌词的不同位置保留为独立条目。参考时间是合成音频时间，不是原唱时间。

3. 检查连续范围，一次填写首尾音素

尚未选定首尾

“完全听不到”＝该音素不存在于片段内；“部分可听”＝仍听得到一部分。无需填写 nxxx 或 phone_index。未知映射会阻止该窗口进入最终评分；可先提交定位及原话，不能删除困难音素。所有记录均不用于训练。

4. 当前片段结论

填写本段后点上方下一段；已经填写的答案会保留。即使范围里有未知映射，也可以照常导出，无需改成待定。已填写的定位、边缘音素和原话全部保留；未解决映射只影响后续评分。

5. 集中说明五种符号（不知道可待定）

这些是你的原始 V4C 写法，不是模型猜出的字。不要求你重新标全曲；说明自己的发音约定即可。系统不会把自由文字直接转换成评分标签。

6. 合并导出

六段都需选择结论；待定允许导出。导出不会启动训练或打开测试预测。候选保持冻结，不依据最终测试结果换权重。
