# DIVA v1.0.3 · Windows x64

[English](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.3/docs/releases/v1.0.3.md)

## 更新内容

- 桌面程序新增中英文切换：默认跟随系统界面语言，无法匹配时使用英文；切换时保留任务状态和已保存的设置。
- 将工作区整理为音频、音素审校和 VSQX 面板，修复较小窗口下播放器与操作控件被裁切的问题。
- 启动时不再下载模型。改为手动开始下载，网络超时设为 30 秒；保留未完成数据，并提供代理、续传和离线导入提示。
- 修复生成的 VSQX 在 VOCALOID4 中显示“空序列”的问题：补齐有效预备小节并使用兼容原生读取器的 VSQ4 序列化；保留音符相对时间、歌词与音素。
- 导出新增 **MIKU V4C 八度适配、保留原调、手动移调**三种方式，手动范围为 −36 至 +36 半音。生成乐谱默认八度适配，导入乐谱默认保留原调；全部音符采用同一移调量，保留旋律音程，并显示实际移调量及仍超出目标音域的音符数。
- 保留原始乐谱和模型预测；音域适配记录在导出文件旁的 provenance JSON 中。

## 安装与升级

下载 **DIVA-Setup-v1.0.3.exe**，安装器会下载并校验本版应用分卷。离线安装时，将三个 **DIVA-Windows-x64-v1.0.3.zip.00x** 分卷放在安装器旁边。请保留完整安装目录，运行 `Any2Xsampa.Desktop.exe`。

安装到新文件夹，可在安装器中选择旧版目录，复用校验通过且与当前清单匹配的模型；已有结果保留在原位置。切换版本前请先关闭旧版。

本次没有更改模型权重。已有已验证模型，以及 [v1.0.2 Release](https://github.com/Hoshino-Rubi/DIVA/releases/tag/v1.0.2) 的四个可选离线模型附件可继续使用，本次不重复上传。

## 验证与限制

本版包含语言、布局、下载超时、导出移调及 VSQX 兼容性定向测试，以及离线安装器、传输层检查、自包含桌面/安装器构建和打包后导出回放。生成文件还通过了本机 VOCALOID4 原生库读取回存检查，366 个音符全部保留。具体发布验证范围见附件 `RELEASE_ACCEPTANCE.json`。

音域适配属于整体音区和编曲设置，不等于旋律或音素识别准确率提升。跨度较大的旋律无法只靠一个整体移调量全部落入较窄的推荐音域，剩余越界音符会如实显示。本次更新没有重新训练或运行模型推理，未作合成人声听感认证。桌面程序和安装器仍未签名；安装器界面目前为中文，安装后的桌面程序支持中英文。
