# DIVA v1.0.2 · Windows x64

[简体中文](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/docs/releases/v1.0.2_CN.md)

DIVA (Dialect Intonation & Vocal Automation), formerly Any2Xsampa, now lives at `Hoshino-Rubi/DIVA`.

- DIVA display branding across desktop, installer, CLI help and Windows product metadata.
- New exported VSQX and diagnostic bundles use the DIVA filename prefix.
- Updates and new pinned installer manifests use the DIVA repository; the new installer still accepts exact, version-bound legacy repository URLs.
- Existing Python imports/commands, internal executables, protocol/JSON contracts, model catalogs and user-data directories stay compatible. No data migration is required.
- Historical releases are preserved. Do not rename old assets or recreate the `any2xsampa` repository while old installers rely on its redirect.

Download **DIVA-Setup-v1.0.2.exe**. For offline application installation, put the three **DIVA-Windows-x64-v1.0.2.zip.00x** volumes beside Setup. The four optional PhoneticXeus/GAME offline-model files are unchanged from v1.0.1. The installed desktop executable remains `Any2Xsampa.Desktop.exe`; the command remains `any2xsampa.cmd`.

This release is **unsigned**. Its acceptance is zero-model software/installation verification, not a recognition-accuracy certificate. No model training, new model inference or model downloads are part of this update. It does not add synthesized vocal audio rendering or claim perfect alignment.

See the [English guide](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/README.md), [中文说明](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/README_CN.md), [migration notes](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/docs/branding_migration.md) and `RELEASE_ACCEPTANCE.json` attached to this release for exact verification scope. GAME weights remain CC BY-NC-SA 4.0; PhoneticXeus remains Apache-2.0. No new overall application-source license is inferred.
