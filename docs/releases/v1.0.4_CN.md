# DIVA v1.0.4 · Windows x64

[English](v1.0.4.md)

## 粤语增强

独立的“粤语增强”页可运行候选4，复用已选 WAV 和现有整首/片段范围。选择解压后的可选模型文件夹，点击“准备模型”，再点击“开始”，完成后“打开结果”。界面保留简洁按钮和状态，详细验证范围记录在本文。

处理链为 MelBand 人声分离 → Whisper small → 完成性选择 → 粤拼 → 规则 IPA → X-SAMPA 导出。分离输出 FLOAT 人声，gain=1，不做补偿前移。优先接受带 EOS 的完整 small 输出；small 失败或不完整时，只接受同一整窗的完整 base 输出，否则明确保留 unknown。结果保留原窗口位置、raw tokens、未知和重复，输出 TXT、JSON 与 `vocal.wav`。

窗口/源帧坐标不等于音素边界。本功能不伪造 `PhoneSegment` 时间，不替换现有 phone 识别、不覆盖其结果，也不接入自动 VSQX。IPA 是粤拼的规则投影，不是独立测量的声学 IPA；X-SAMPA 仍仅为导出表示。缺失声调、未解决的重复声学证据保留 unknown。

## 可选模型与运行环境

可选模型包为 `DIVA-Cantonese4-Models-v1.0.4.zip`。解压后，在粤语增强页选择解压后的模型文件夹；默认位置为 `models/cantonese4`。公开 ZIP 不包含分离器作者代码。

开始前显式点击“准备模型”。首次准备时，仅对缺失的分离器源码/配置，从固定上游 commit 外部获取4个小文件，按固定 SHA256 校验，网络超时30秒，可使用现有代理设置。4个文件为 `config_vocals_mel_band_roformer.yaml`、`__init__.py`、`attend.py`、`mel_band_roformer.py`。已自备且校验匹配时零网络。启动及后台任务不会自动下载源码。

分离使用 GPU，识别使用 CPU 四线程。GPU 不可用或分离失败会明确报告，不静默回退为 CPU 分离。准备完成后的推理离线运行，不启动下载。

主程序 payload 已补齐17个固定 wheel 的音频处理和分离依赖，总计170,899,517 bytes，包括 `librosa`、`soxr`、`einops`、`rotary_embedding_torch`、`beartype` 等，复用 phonetic runtime 已有的 Torch / Transformers。依赖 import 与44.1 kHz → 16 kHz 重采样工程检查已通过。模型专用执行逻辑通过可替换 adapter 接入；依赖清单与核验细节见 `RELEASE_ACCEPTANCE`。

## 已记录的准确度证据

原 `RESULTS_CN` 报告及 `VOCAL_AB_SCORE.json` 对照候选3混音输入与候选4分离人声输入，保持相同 small/base 完成性规则。固定 Train6/7 两歌共 843 个作者无调粤拼音节，每臂均为 32 个源时钟窗口；保留全部输出、重复和未知，不改变分母。

E=替换+删除+插入，TP=N−替换−删除，FP=替换+插入，FN=替换+删除。表中箭头均为混音 → 人声输入。

| 固定输入 | N | E | TP | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: |
| Train6 | 405 | 105 → 60 | 306 → 351 | 69 → 53 | 99 → 54 |
| Train7 | 438 | 200 → 74 | 247 → 371 | 93 → 51 | 191 → 67 |
| 固定两歌池 | 843 | 305 → 134 | 553 → 722 | 162 → 104 | 290 → 121 |

净变化为 E−171、TP+169、FP−58、FN−169。编辑错误相对混音基线减少 56.0656%，不能写成“整体准确率提高56%”。两首汇总 E 均未退化，不表示每窗或每个音素都改善。

两臂均为 32/32 窗完整，最终失败、缺失歌曲、unknown-token 窗均为0。混音 small 原始31/32完整，1窗整窗回退到完整 base；人声 small 32/32完整。四组识别共128次调用，调用异常0。分离共4次启动：2次在 forward 前导入失败，1次完成首歌后中断，最后仅恢复第二首；已完成首歌复用，未重跑。失败启动与中断均保留，不能用“最终失败0”抹去。

这是固定研究对照，不是独立盲测；既往参考暴露偏差保留，预训练重叠 unknown。作者歌词可能未覆盖对白/filler，因此 FP 是编辑对齐计数，不是完整声学误报真值。参考时钟对齐和分离器时延未独立证实，同帧数且不做补偿移位不等于零时延。声调、phone 边界、短音/重复音事件、音符准确率和 VOCALOID 质量均未证实，不能推广为广泛粤语泛化或线上整体准确度提升。
