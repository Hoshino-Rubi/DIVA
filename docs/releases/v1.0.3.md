# DIVA v1.0.3 · Windows x64

[简体中文](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.3/docs/releases/v1.0.3_CN.md)

## Changes

- Added English/Chinese switching in the desktop app. The default follows the system UI language; unsupported languages use English. Switching languages preserves task state and saved preferences.
- Reorganized the workspace into audio, phoneme review and VSQX panels. Fixed clipping of the audio player and controls in smaller windows.
- Startup no longer downloads models. Model downloads start explicitly, use a 30-second network timeout, retain partial data, and explain proxy, resume and offline-import options.
- Fixed generated VSQX projects appearing as an empty sequence in VOCALOID4. Generated projects now include a valid count-in and native-compatible VSQ4 serialization while preserving relative note timing, lyrics and phonemes.
- Added three VSQX export pitch modes: **MIKU V4C octave adaptation**, **original pitch**, and **manual transpose** (−36 to +36 semitones). Generated scores default to octave adaptation; imported scores default to their original pitches. Every note receives one uniform shift, preserving melodic intervals. Export results report the actual shift and remaining notes outside the target range.
- Kept original saved scores and model predictions unchanged. Pitch adaptation is recorded in the export provenance file.

## Install or update

Download **DIVA-Setup-v1.0.3.exe**. Setup downloads and verifies this version's application volumes. For offline installation, place all three **DIVA-Windows-x64-v1.0.3.zip.00x** volumes beside Setup. Keep the complete installed folder; launch `Any2Xsampa.Desktop.exe`.

Install into a new folder. You may select a previous installation in Setup to reuse matching, verified models; existing results remain in their original locations. Close the old app before switching versions.

No model weights changed. Existing verified models and the four optional offline-model attachments from the [v1.0.2 Release](https://github.com/Hoshino-Rubi/DIVA/releases/tag/v1.0.2) remain usable. They are not duplicated in this release.

## Verification and limits

The release includes targeted language, layout, timeout, export-pitch and VSQX compatibility tests, offline installer/transport checks, self-contained desktop and installer builds, and packaged export replay. Generated VSQX was also read and saved through the installed VOCALOID4 native library with all 366 notes retained. See the attached `RELEASE_ACCEPTANCE.json` for the exact release checks.

The pitch repair is a register/arrangement option, not proof of accurate melody or phoneme recognition. A single global shift cannot fit every wide melody inside a narrow recommended voice range; remaining outliers are reported. No new model training or inference was run for this update, and no synthesized-audio quality certification is claimed. The desktop and installer remain unsigned. The installer interface is currently Chinese; the installed desktop supports both English and Chinese.

PhoneticXeus retains Apache-2.0; GAME weights retain CC BY-NC-SA 4.0, including its non-commercial restriction. No new overall application-source license is inferred. Previous releases and their assets are preserved.
