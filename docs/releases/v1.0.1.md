# Any2Xsampa v1.0.1

[简体中文](https://github.com/Hoshino-Rubi/any2xsampa/blob/v1.0.1/docs/releases/v1.0.1_CN.md)

Windows x64 application release candidate. Publish as stable only after the release acceptance report passes all required gates.

- One Setup executable downloads pinned application volumes, checks sizes/SHA256 and installs without a separate Python or .NET setup. Offline volumes remain supported.
- Explicit resume/cancel, verified previous-model reuse, independent version installation and model/user-data-preserving uninstall.
- Shared results/settings and verified download cache across application versions.
- Explicit, read-only update check; no silent application or checkpoint replacement.
- Local diagnostic ZIP excludes audio, predictions, raw logs, usernames, paths and credentials.

Download Any2Xsampa-Setup-v1.0.1.exe. For offline installation, put the three Any2Xsampa-Windows-x64-v1.0.1.zip.00x files beside Setup. The optional PhoneticXeus and GAME model attachments are unchanged.
