# Any2Xsampa v1.0.1

[English](https://github.com/Hoshino-Rubi/any2xsampa/blob/v1.0.1/docs/releases/v1.0.1.md)

Windows x64 正式版候选；所有必需验收通过后才发布为正式版。

- 单安装器下载固定分卷、核验大小与 SHA256 后安装，无需另装 Python/.NET。
- 显式续传与取消；旧版模型只按哈希复用。新版本独立安装，卸载保留模型和用户数据。
- 设置、结果与已验证下载缓存跨版本保留。
- 仅明确点击后检查更新，不自动替换程序或模型。
- 诊断 ZIP 不含音频、预测、原始日志、用户名、路径或凭据。

下载 Any2Xsampa-Setup-v1.0.1.exe；离线时把三个应用分卷放在安装器旁边。四个离线模型附件与预览版保持一致。
