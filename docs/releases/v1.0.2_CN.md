# DIVA v1.0.2 · Windows x64

[English](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/docs/releases/v1.0.2.md)

DIVA（Dialect Intonation & Vocal Automation）原名 Any2Xsampa，仓库迁至 `Hoshino-Rubi/DIVA`。

- 桌面、安装器、CLI 帮助及 Windows 产品信息使用 DIVA 名称。
- 新导出的 VSQX 与诊断包使用 DIVA 文件名前缀。
- 更新检查、新版安装清单使用 DIVA 仓库；新版安装器仍接受绑定精确版本的旧仓库地址。
- 保留 Python 包和命令、内部 EXE 名称、协议与 JSON 契约、模型清单和用户数据目录；无需搬动设置、模型和已有结果。
- 历史发布保留；不要改名旧附件，也不要重建名为 any2xsampa 的仓库以免破坏旧安装器依赖的跳转。

下载 **DIVA-Setup-v1.0.2.exe**。离线安装程序时，把三个 **DIVA-Windows-x64-v1.0.2.zip.00x** 放在安装器旁边。四个可选 PhoneticXeus / GAME 离线模型附件与 v1.0.1 相同。安装后的桌面 EXE 仍为 `Any2Xsampa.Desktop.exe`，CLI 仍为 `any2xsampa.cmd`。

本版**未签名**。验收范围是零模型的软件和安装验证，不是识别准确率认证。本次不训练、不新增模型推理、不下载模型，不新增合成人声音频渲染，也不承诺完美对齐。

使用方法见[英文 README](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/README.md)、[中文说明](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/README_CN.md)、[迁移说明](https://github.com/Hoshino-Rubi/DIVA/blob/v1.0.2/docs/branding_migration.md)。精确验证范围见本 Release 附件 `RELEASE_ACCEPTANCE.json`。GAME 权重仍为 CC BY-NC-SA 4.0，PhoneticXeus 为 Apache-2.0；不替仓库所有者选择应用源码许可证。
